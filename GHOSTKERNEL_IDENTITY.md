# GhostKernel Identity

Knowledge Never Dies.

GhostKernel is not just a YouTube Music fork with new paint.

GhostKernel is a KornDog music player built around how Joey actually listens:
loud in the car, deep in the catalog, emotional when it needs to be, and always chasing the next song that feels like a crate dig.

## Core Rule

Stability first.
Sound second.
Discovery third.
Flash last.

If a feature makes playback worse, delays track changes, muddies the audio, or breaks the daily-driver feel, it does not ship.

## What GhostKernel Is

- A music-first Android player
- A KornDog-branded listening system
- A personal discovery engine
- A bridge between streaming habits and vinyl culture
- A daily driver, not a demo toy

## What GhostKernel Is Not

- Not a bloated YouTube clone
- Not a science project that breaks every build
- Not an EQ experiment machine
- Not a feature dump
- Not something that trades stability for noise

## Audio Baseline

v1.2 Audio Safe is the locked baseline.

- PCM gain cap: 1.9x
- Loudness Boost works cleanly
- Normalize Volume off by default
- DNA Mood EQ off by default
- No LoudnessEnhancer mud
- No per-song audio chaos

Future audio changes must prove they are cleaner and more stable than this baseline.

## Next Chapters

### 1. Music Brain

GhostKernel should learn what the user actually plays and turn that into useful discovery.

Examples:
- Recently played artists
- Most repeated tracks
- Artist connections
- Ghost Picks based on real listening history

### 2. Better Library

Library should feel like home base.

Examples:
- Playlist thumbnails
- Playlist song navigation
- Liked Music shortcut
- RAC Radio shortcut
- Recently played shortcut

### 3. Queue Intelligence

The queue should explain why songs are there.

Examples:
- Because you played Sleep Token
- Because this matches your Heavy DNA
- Because this fits Late Night
- Because this artist connects to your history

### 4. GhostKernel Personality

The app should feel alive without getting annoying.

Examples:
- Knowledge Never Dies
- Ghost Picks
- Crate Digs
- Vinyl Therapy
- KornDog DNA
- subtle Joey voice, not cartoon overload

## Release Rule

Every release needs a clear purpose.

v1.2 = Audio Safe foundation.
v1.3 = Library and playlist polish.
v1.4 = Music Brain begins.
v1.5 = Ghost Picks.
