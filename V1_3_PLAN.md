# GhostKernel v1.3 Plan

Theme: Make GhostKernel feel smarter, not louder.

## Goal

v1.3 begins the Ghost Brain era.

No audio changes unless a real bug appears.

## Priorities

1. Playlist tap navigation
   - Library playlists must open into song lists reliably.

2. Playlist thumbnails
   - Library should look alive, not text-only.

3. Listening memory
   - Save recently played songs, artists, and albums locally.

4. Ghost Picks foundation
   - Start with simple recommendations based on recent artists and moods.

5. Identity polish
   - Add small GhostKernel language in the UI:
     - Ghost Picks
     - Crate Digs
     - Knowledge Never Dies
     - Music DNA

## Hard Rules

- Do not touch PCM gain.
- Do not rework audio effects.
- Do not add slow per-song processing.
- Do not break playback for discovery features.
- If it delays track changes, it does not ship.

## Release Target

v1.3 should make the Library and listening memory better while keeping v1.2 Audio Safe untouched.
